# TeleAgent 阅读与学习指南：从入门到团队落地

这是一条面向新手、任务实践者和团队负责人的 TeleAgent 学习路线。你不必从头背功能：先找到当前最接近的工作问题，完成一项真实任务，再沿着使用手册、实战案例、进阶系统和团队落地逐步深入。

## TeleAgent 新手入门路线

从 [第一篇：先把 TeleAgent 用起来](/bluebook/第一篇%20使用手册：先把%20TeleAgent%20用起来/) 开始，依次完成：

1. 下载、安装和登录
2. 认识主界面、任务与工作区
3. 完成第一个可检查的任务
4. 加载一个真正用得上的 Skills 技能
5. 再学习 MCP 连接器、长期记忆、定时任务和多模型切换

建议边读边做，不要只浏览截图。每完成一章，至少留下一个可复用的提示词、模板或操作记录。

## 按真实任务选择 TeleAgent 教程

直接进入 [第二篇：案例篇](/bluebook/第二篇%20案例篇：从一项任务到一支%20AI%20团队/) 或 [案例集](/cases/)，按问题选择章节：

- 处理 Excel、Word、PPT：2.1
- 整理文件和桌面：2.2
- 数据分析和经营报告：2.3
- 深度调研和信息整合：2.4
- 合同审核和法务辅助：2.5
- 知识库构建：2.6
- 会议纪要和语音转写：2.7
- 招标信息监测：2.8
- PPT 生成：2.9
- IM 集成和消息推送：2.10
- OCR 识别：2.11

案例跑通后，再回到第三篇，把你的做法整理为 Skills、自动化或多 Agent 系统。

## TeleAgent 团队落地路线

重点阅读 [第三篇：进阶篇](/bluebook/第三篇%20进阶篇：把案例变成自己的工作系统/) 与 [第四篇：岗位与行业落地](/bluebook/第四篇%20岗位与行业落地：从个人效率到组织能力/)。

团队实践建议同时记录：

- 输入资料和权限边界
- 任务拆解方式和失败回退
- 交付物的验收标准
- 可以复用的 Skills、模板和自动化
- 哪些步骤必须由人确认
