# 4.2 行政文秘岗位

## 岗位画像

行政文秘是组织的「运转枢纽」——公文起草、会议管理、日程协调、文档归档，工作量大且重复性高，是 TeleAgent 落地价值最直观的岗位之一。

### 核心痛点

| 痛点 | 传统方式 | 影响 |
| --- | --- | --- |
| 公文起草耗时 | 逐字逐句手写 | 占用大量时间 |
| 会议纪要滞后 | 会后手工整理 | 交付延迟 |
| 文档归档混乱 | 手工分类命名 | 查找困难 |
| 日程协调繁琐 | 反复沟通确认 | 效率低下 |

## 4.2.1 L1：单次辅助

### 公文起草

```
请起草一份关于开展2026年安全生产月活动的通知，
要求格式规范、语气正式、包含活动安排和时间表。
```

| 能力 | 技能 |
| --- | --- |
| 语音转写 | 语音转写技能（技能广场安装或自研） |
| 文档生成 | @docx（Word 文档助手） |
| 指令理解 | 内置能力 |

### 会议纪要

```
请对这段会议录音进行智能分析，生成结构化会议纪要，
包含会议主题、讨论要点、关键决议和待办事项。
```

| 能力 | 技能 |
| --- | --- |
| 语音转写 | 语音转写技能（技能广场安装或自研） |
| 文档生成 | @docx |

### 文档格式转换

```
请将这份 PDF 文件转为 Word 文档，保留原格式。
```

| 能力 | 技能 |
| --- | --- |
| 文档转换 | @markitdown + @docx |

## 4.2.2 L2：流程固化

### 自研技能：周报自动生成器

| 步骤 | 内容 |
| --- | --- |
| 触发方式 | @周报生成器 |
| 输入 | 本周工作笔记（Markdown） |
| 处理 | 按六章节分类汇总、提炼要点 |
| 输出 | docx 周报文档 |

## 4.2.3 L3：协同自动化

### 会议管理全链路

| 环节 | 自动化 | 人工 |
| --- | --- | --- |
| 会前准备 | 自动生成议程文档 | 确认议程 |
| 会中记录 | 自动录音转写 | 主持会议 |
| 会后纪要 | 自动生成并分发 | 审核关键决议 |
| 待办追踪 | 自动提取并推送 | 执行待办事项 |
| 归档整理 | 自动分类命名归档 | 确认归档位置 |

### 技能组合

| 技能 | 职责 | 协同方式 |
| --- | --- | --- |
| 语音转写技能 | 语音转写 | 前置处理 |
| @docx | 生成纪要文档 | 接收转写结果 |
| @wecom-push（企业微信推送） | 推送纪要到群 | 后置通知 |
| 自研归档技能 | 分类命名归档 | 串联最后一步 |

## 4.2.4 效果对比

> 以下效果数据为参考值，实际效果以具体使用场景为准。

| 工作项 | 传统方式 | L1 | L2 | L3 |
| --- | --- | --- | --- | --- |
| 公文起草 | 2~3 小时 | 15 分钟 | 5 分钟（模板化）| 3 分钟（标准化）|
| 会议纪要 | 2~3 小时 | 15 分钟 | 10 分钟（含待办）| 5 分钟（全自动）|
| 周报撰写 | 1~2 小时 | 30 分钟 | 5 分钟（@技能）| 0（定时自动）|
| 文档归档 | 每次手工 | 手工 | 按规则自动 | 全链路自动 |

## 4.2.5 落地建议

| 优先级 | 建议 | 理由 |
| --- | --- | --- |
| 高 | 先从会议纪要开始 | 效果最直观，建立信心 |
| 高 | 第二步做周报自动化 | 高频重复，ROI 高 |
| 中 | 开发公文模板技能 | 减少起草时间 |
| 中 | 设置日程提醒定时任务 | 提升日常管理效率 |
| 低 | 构建全链路会议管理 | 需要多技能协作，前述稳定后再做 |

## 本章小结

行政文秘岗位是 TeleAgent 落地的「桥头堡」——工作量大、重复性高、效果直观。从会议纪要到周报自动化，每一步都能明显感受到效率提升。关键是**先从最有痛点的场景切入，再逐步扩展到全流程自动化**。
