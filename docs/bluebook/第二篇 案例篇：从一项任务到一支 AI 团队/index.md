# 第二篇 案例篇：从一项任务到一支 AI 团队

> 从单项任务到工作流，从个人效率到团队能力——11 个真实案例，让 TeleAgent 在你的工作中真正流动起来。

## 本篇定位

第一篇教你"怎么用"，第二篇教你怎么"用得好"。

本篇通过 11 个真实办公场景案例，展示 TeleAgent 如何将第一篇学到的基础能力组合起来，解决实际工作中的完整任务。每个案例都遵循统一结构：说清目标、给出指令、展示流程、验收交付。

## 阅读建议

### 按难度递进

1. **入门案例**（2.1~2.2）：从最常用的办公文档和文件管理开始，零基础上手
2. **中级案例**（2.3~2.5、2.7、2.9、2.11）：组合多项能力解决完整任务，适合已读完第一篇的用户
3. **进阶案例**（2.6、2.8、2.10）：涉及定时任务、MCP 集成等高级能力，适合想打造自动化工作流的用户

### 按岗位匹配

| 你的岗位 | 优先阅读 |
| --- | --- |
| 行政文秘 | 2.1、2.2、2.7、2.9 |
| 财务审计 | 2.1、2.3、2.11 |
| 法务合规 | 2.5、2.6 |
| 销售市场 | 2.3、2.4、2.8、2.9 |
| 技术研发 | 2.4、2.6、2.10 |
| 管理岗位 | 2.3、2.4、2.8、2.10 |

### 每个案例的统一结构

```
1. 案例背景：什么岗位、什么场景、什么痛点
2. 目标定义：交付什么成果、验收标准是什么
3. 操作步骤：具体指令 → 执行流程 → 中间产物
4. 能力组合：用到了第一篇的哪些能力
5. 效果对比：传统方式 vs TeleAgent 方式
6. 进阶玩法：如何自动化、如何复用
```

## 前置要求

阅读本篇前，请确保你已掌握第一篇的核心内容：

- 会下载安装并登录 TeleAgent（1.2）
- 了解工作空间和文件管理（1.3）
- 完成过至少一个任务（1.4）
- 安装并使用过至少一个 Skills 技能（1.5）
- 了解 MCP 连接器的基本概念（1.6）

::: tip 边读边练
每个案例都可以边读边操作。建议先通读一遍了解全貌，再回到开头按步骤实操。实操时把案例中的文件替换成你自己的真实工作文件，效果更好。
:::
