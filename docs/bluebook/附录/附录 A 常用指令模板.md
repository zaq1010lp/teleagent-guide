# 附录 A 常用指令模板

本附录按场景分类整理 TeleAgent 常用指令模板，可直接复制修改使用。

## A.1 文档处理类

### Excel 数据处理

```
请处理这份 Excel 表格：
1. 删除重复数据
2. 按 [列名] 从高到低排序
3. 增加一列 [新列名]，计算 [公式说明]
4. 输出处理后的新文件
```

### Word 文档生成

```
请生成一份 [文档类型] Word 文档：
主题：[主题]
结构：[章节结构]
要求：[格式要求]
字数：[字数范围]
```

### PPT 演示制作

```
请根据 [源文件/大纲] 生成 PPTX 演示文稿：
风格：[商务正式/极简/科技感]
页数：[X~Y 页]
要求：每页不超过 5 条要点，数据用表格展示
```

### PDF 文档处理

```
请将这份 [PDF/Word/Markdown] 文件转为 [目标格式]，
保留 [原格式/表格结构/图片]。
```

## A.2 数据分析类

### 经营数据分析

```
请根据这份经营数据 Excel，生成分析报告：
1. 按维度 [区域/产品线/时间] 汇总统计
2. 计算环比和同比变化
3. 标注异常指标（涨跌超 [X]%）
4. 生成可视化图表
5. 输出分析报告 Word 文档
```

### 数据看板

```
请根据这份数据生成数据看板：
维度：[X轴]、[Y轴]、[分组]
图表类型：[柱状图/折线图/饼图]
要求：[交互筛选/趋势线/对比标注]
```

## A.3 信息检索类

### 深度调研

```
请对 [主题] 进行深度调研：
范围：[行业/公司/技术/市场]
要求：
1. 多源搜索，交叉验证
2. 包含数据、案例和趋势分析
3. 标注信息来源
4. 输出结构化研究报告
```

### 招标信息监测

```
请搜索最近 [N] 天内包含 [关键词] 的招标信息：
1. 覆盖主要政府采购网站
2. 提取项目名称、单位、预算、日期
3. 生成含预算分析的 HTML 报告
4. 支持按关键词和地区筛选
```

## A.4 合同法务类

### 合同审核

```
请审核这份合同，进行三层审查：
1. 基础审查（格式和条款完整性）
2. 商业审查（价格、交付、违约条款）
3. 法律审查（合规、风险、管辖）
添加批注标注，不改原文，生成摘要和业务流程图。
```

### 文档比对

```
请比对这两份文档，列出所有差异：
差异维度：[内容/格式/数据]
输出：差异对照表 + 相似度评分
```

## A.5 会议记录类

### 会议纪要

```
请对这段会议录音进行智能分析：
1. 语音识别生成完整转写
2. 提取讨论要点和关键决议
3. 列出待办事项（标注责任人和截止时间）
4. 生成脑图
5. 输出 Word 纪要文档
```


## A.10 通用模板结构

编写指令时建议包含以下要素：

| 要素 | 说明 | 示例 |
| --- | --- | --- |
| 任务类型 | 要做什么 | 生成/分析/搜索/审核 |
| 输入说明 | 提供什么 | 文件名、数据范围、关键词 |
| 输出规范 | 要什么格式 | docx/xlsx/html/json |
| 质量要求 | 有什么约束 | 字数、页数、准确率 |
| 特殊指令 | 额外要求 | 标注异常、保留格式、去重 |
