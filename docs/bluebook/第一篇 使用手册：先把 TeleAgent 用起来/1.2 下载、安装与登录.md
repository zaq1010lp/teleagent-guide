# 1.2 下载、安装与登录

## 本章目标

完成 TeleAgent 客户端的下载与安装，成功登录并进入工作界面——全程不超过 5 分钟。

## 1.2.1 系统要求

TeleAgent 桌面版支持 Windows 和 macOS 双平台：

| 项目 | Windows 最低配置 | Windows 推荐配置 | macOS 最低配置 |
| --- | --- | --- | --- |
| 操作系统 | Windows 10 64 位（Windows Server 不低于 2016） | Windows 11 64 位 | macOS 13（Ventura） |
| 内存 | 8 GB | 16 GB 及以上 | 8 GB |
| 磁盘空间 | 20 GB 可用空间（SSD 推荐） | 50 GB 以上 NVMe SSD | 20 GB 可用空间（SSD 推荐） |
| 网络 | 需要联网（首次登录及模型调用） | 稳定宽带连接 | 需要联网 |

::: tip 为什么需要联网？
TeleAgent 的核心推理能力来自云端星辰大模型，但所有文件操作和数据处理均在本地完成。联网是为了调用模型能力，你的文件不会上传到云端。
:::

## 1.2.2 下载渠道

TeleAgent 提供以下官方下载渠道：

1. **天翼 AI 开放平台**：访问 [TeleAgent 产品页](https://www.teleai.com.cn/product/teleagent)，选择适合的版本进行下载
2. **官方直链下载**：通过中国电信官方渠道获取安装包
3. **企业内部分发**：企业版用户由管理员统一分发安装包

::: warning 安全提示
请仅从上述官方渠道下载安装包。第三方下载站可能捆绑恶意软件或篡改程序，存在数据安全风险。
:::

## 1.2.3 安装步骤

### Windows 安装流程

1. **下载安装包**：访问天翼 AI 开放平台 TeleAgent 产品页，选择 Windows 版本下载（文件大小约 400 MB）
2. **运行安装程序**：双击安装包，如出现用户账户控制（UAC）提示，点击"是"继续
3. **选择安装用户及位置**：选择安装路径，默认安装至 `C:\Program Files\StarAI Desktop\`，也可自定义路径
4. **等待安装完成**：安装过程约 1-2 分钟，完成后自动创建桌面快捷方式
5. **首次启动**：双击桌面图标启动 TeleAgent
6. **首次启动网络授权**：首次启动时系统会弹出网络访问授权弹窗，请选择"允许"

### macOS 安装流程

1. **下载安装包**：访问 TeleAgent 产品页，选择 macOS 版本下载
2. **安装应用**：双击 `.dmg` 文件，将 TeleAgent 图标拖入 Applications 文件夹
3. **首次启动**：在 Applications 中找到 TeleAgent，右键选择"打开"（首次需绕过 Gatekeeper）

### 安装后的目录结构

> 以下为安装目录的结构示意图，实际路径和内容以安装版本为准。

```
TeleAgent/
├── TeleAgent.exe          # 主程序
├── resources/             # 应用资源
├── skills/                # 内置技能目录
└── share/
    └── TeleAgent/
        ├── memory/        # 长期记忆存储
        └── skills-metadata.json  # 技能元数据
```

## 1.2.4 账号登录

TeleAgent 支持多种登录方式：

### 个人版登录

1. **启动客户端**：打开 TeleAgent 桌面端
2. **选择登录方式**：
   - **手机号验证码登录**：输入手机号，获取短信验证码完成登录
   - **账户邮箱密码登录**：输入注册邮箱和密码完成登录
3. **首次登录引导**：系统会展示简短的新手引导，介绍核心功能区域
4. **进入工作台**：完成引导后进入主界面

### 企业版登录

企业版用户由管理员分配账号：

1. 管理员在超管后台创建租户和用户账号
2. 用户使用分配的账号密码登录客户端
3. 首次登录需强制修改初始密码
4. 登录后自动关联所属租户的模型配置和技能资源

::: tip 企业版与个人版的区别
个人版使用公有云模型服务，注册即用；企业版支持私有化部署，由企业管理员统一管控模型资源、Token 配额和安全策略，适用于对数据主权有严格要求的场景。
:::

## 1.2.5 更新机制

TeleAgent 采用「自动检查 + 用户确认」的更新策略，兼顾及时性与可控性：

- **自动检查**：客户端在运行过程中自动检查新版本，发现新版本时弹出提示「检测到当前有可更新版本，是否更新？」，由用户自主决定
- **手动检查**：在「设置 - 关于」中可手动检测更新，检测到新版本后手动发起更新
- **更新安装**：用户确认后执行更新，更新前建议备份重要文件，运行中的任务会自动暂停
- **技能更新**：技能广场的技能支持独立的更新机制，不影响主程序

## 1.2.6 常见安装问题

| 问题 | 解决方案 |
| --- | --- |
| 安装时提示"缺少 DLL" | 安装最新的 Visual C++ 运行库后重试 |
| 杀毒软件拦截安装 | 将 TeleAgent 安装目录加入白名单后重新安装 |
| 启动后白屏 | 检查显卡驱动是否为最新版本，或尝试以管理员身份运行 |
| 登录提示"网络异常" | 检查防火墙设置，确保客户端可访问外网 |
| 安装路径含中文导致异常 | 尽量使用默认路径或纯英文路径 |
| 浏览器下载提示安全警告 | 浏览器可能对未知来源安装包提示风险，选择"保留"或"继续下载"即可 |
