# 1.8 定时任务与自动化

## 本章目标

掌握 TeleAgent 的定时任务功能，让重复性工作实现自动化执行——设定一次，持续受益。

## 1.8.1 什么是定时任务

定时任务是 TeleAgent 的核心能力之一，它允许你设定按特定时间规则自动执行的任务：

- **周期性任务**：每天、每周、每月固定时间执行
- **一次性任务**：在指定的未来时间点执行一次

### 定时任务的价值

| 传统方式 | 定时任务 |
| --- | --- |
| 每天手动搜索行业新闻 | 每天早上 8 点自动生成新闻简报 |
| 每周五手动汇总周报数据 | 每周五下午 5 点自动生成周报初稿 |
| 每月初手动做经营分析 | 每月 1 号自动生成经营分析报告 |
| 忘记备份重要文件 | 每天自动备份指定文件夹 |

## 1.8.2 任务的调度规则

TeleAgent 支持两种调度方式：

### Cron 表达式

Cron 是一种标准的时间调度语法，由 5 个字段组成：

```
分钟  小时  日期  月份  星期
 *     *     *     *     *
```

| 字段 | 取值范围 | 示例 |
| --- | --- | --- |
| 分钟 | 0-59 | 0 = 整点, 30 = 半点 |
| 小时 | 0-23 | 9 = 上午9点, 18 = 下午6点 |
| 日期 | 1-31 | 1 = 每月1号 |
| 月份 | 1-12 | * = 每月 |
| 星期 | 0-6（0=周日） | 1-5 = 周一到周五 |

**常用 Cron 示例**：

| 表达式 | 含义 |
| --- | --- |
| `0 9 * * 1-5` | 每个工作日早上 9 点 |
| `0 17 * * 5` | 每周五下午 5 点 |
| `0 8 1 * *` | 每月 1 号早上 8 点 |
| `0 */2 * * *` | 每 2 小时执行一次 |
| `30 9 * * *` | 每天 9:30 |

### 一次性任务

指定具体的时间点执行：

```
明天下午 3 点提醒我准备季度评审材料
```

TeleAgent 会解析自然语言时间描述，创建一次性定时任务。

## 1.8.3 创建定时任务

### 方式一：自然语言创建

直接用自然语言描述：

```
帮我创建一个定时任务：
- 每周一上午 9 点
- 从 Jira 拉取各项目 Bug 统计数据
- 生成简报文档
- 文件保存到"项目周报"文件夹
```

### 方式二：从预设模板创建

TeleAgent 可能提供常见任务的预设模板，具体模板以实际产品为准。选择模板后，按提示填入参数即可。

## 1.8.4 任务管理

### 查看定时任务

在任务管理面板中可以查看所有已创建的定时任务：

| 信息 | 说明 |
| --- | --- |
| 任务名称 | 任务的标识名称 |
| 调度规则 | Cron 表达式或一次性时间 |
| 上次执行 | 上次运行的时间和结果 |
| 下次执行 | 下次计划执行的时间 |
| 状态 | 运行中 / 已暂停 / 已完成 |

### 编辑与暂停

- **编辑**：修改任务的调度规则或执行内容
- **暂停**：临时停止任务执行，不删除
- **恢复**：继续执行已暂停的任务
- **删除**：永久删除任务

### 执行历史

每个定时任务都保留执行历史记录，包括：
- 执行时间
- 执行结果（成功/失败）
- 交付的文件
- 失败时的错误信息

## 1.8.5 实操：创建每日新闻简报任务

### 步骤 1：描述任务

```
帮我创建一个定时任务：
- 每天早上 8 点
- 搜索 AI、云计算、电信行业最新新闻
- 从 36Kr、腾讯新闻、华尔街见闻获取信息
- 生成一份 HTML 新闻简报
- 包含标题、摘要和来源链接
- 保存到桌面"每日简报"文件夹
```

### 步骤 2：确认任务配置

TeleAgent 会展示解析后的任务配置供你确认：

- 调度规则：`0 8 * * *`（每天 8:00）
- 信息源：36Kr、腾讯新闻、华尔街见闻
- 关键词：AI、云计算、电信行业
- 输出格式：HTML
- 保存路径：桌面"每日简报"文件夹

### 步骤 3：验证执行

可以点击"立即执行一次"来验证任务是否能正常运行，确认输出效果后再切换为定时执行。

## 1.8.6 定时任务的最佳实践

### 任务拆分原则

- 单个定时任务只做一件事，避免过于复杂
- 如果需要多步骤，在任务描述中明确步骤顺序
- 为任务设置合理的超时时间，避免长时间卡住

### 结果通知

结合 MCP 工具，定时任务完成后可以自动发送通知：

```
任务完成后通过企业微信群发送消息通知，附上交付文件
```

### 失败处理

- 设置失败重试策略（如重试 3 次，间隔 5 分钟）
- 关键任务建议配置失败告警通知
- 定期检查执行历史，及时发现问题

::: tip TeleAgent 需要保持运行
定时任务需要 TeleAgent 客户端处于运行状态才能执行。如果客户端关闭，错过的任务将被跳过。
:::

## 1.8.7 企业版定时任务

企业版 TeleAgent 的定时任务还支持：

- **任务权限管控**：管理员可限制用户可创建的任务类型
- **资源配额**：定时任务消耗的 Token 计入租户配额
- **执行审计**：所有定时任务的执行记录纳入操作审计
- **安全审查**：任务内容受 AIGC 安全围栏检测

## 本章小结

定时任务让 TeleAgent 从"被动响应"进化为"主动工作"。设定好规则后，重复性工作将自动完成，你可以将精力集中在更有价值的决策和创造上。下一章介绍多模型切换——让 TeleAgent 根据任务需要灵活选用最合适的模型。
