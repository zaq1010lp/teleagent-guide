# 第一篇 使用手册：先把 TeleAgent 用起来

> 从 0 到 1：安装、界面、第一个任务、Skills 技能、MCP 连接器、长期记忆、定时任务、多模型切换与安全控制。

## 本篇导读

本篇是 TeleAgent 的入门使用手册。你将从下载安装开始，逐步了解主界面和任务工作区，完成第一个可验收的任务，加载第一个 Skills 技能，学习 MCP 连接器接入外部工具，配置长期记忆实现个性化，设置定时任务实现自动化，掌握多模型切换策略，最后了解安全与权限控制机制。

建议按顺序阅读，每章边读边做。完成本篇后，你将具备使用 TeleAgent 独立完成日常办公任务的能力。
