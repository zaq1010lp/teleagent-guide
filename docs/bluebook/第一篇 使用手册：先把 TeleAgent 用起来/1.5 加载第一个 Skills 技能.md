# 1.5 加载第一个 Skills 技能

## 本章目标

理解技能（Skills）的概念，从技能广场安装第一个技能，并通过 @ 调用完成一次专项任务。

## 1.5.1 什么是技能

技能是扩展 TeleAgent 能力的功能模块。如果把 TeleAgent 比作一位新员工，技能就是他掌握的各种专业工具和操作手册：

- **内置技能**：安装即可用，涵盖 Excel 处理、Word 撰写、PPT 制作、PDF 生成、OCR 识别等核心办公能力
- **技能广场技能**：由平台或社区提供，覆盖合同审核、深度调研、招标监测、信息图制作等专业场景
- **自定义技能**：用户自主开发的技能，打包为 ZIP 格式发布

### 技能 vs 普通对话

| 场景 | 不用技能 | 使用技能 |
| --- | --- | --- |
| 合同审核 | 逐条粘贴合同文本让模型分析，输出是纯文字建议 | 上传合同文件，一键生成批注版文档，风险评估分级标注 |
| Excel 处理 | 模型给出操作建议，用户手动执行 | 直接生成处理好的 Excel 文件，公式和格式完整保留 |
| 招标监测 | 人工每天搜索各网站 | 自动定时抓取多源招标信息，生成 HTML 报告 |

## 1.5.2 技能广场

技能广场是 TeleAgent 的技能商店，提供丰富的预置技能：

### 访问方式

在工作台的技能管理区域点击"技能广场"入口，进入技能浏览页面。

### 技能分类

技能广场的技能按场景分类：

| 分类 | 典型技能示例 |
| --- | --- |
| 办公文档 | Excel 表格助手、Word 文档助手、PPT 生成与编辑 |
| 信息收集 | 深度调研、新闻聚合、招标信息监测 |
| 内容创作 | 信息图制作、海报设计、文案生成 |
| 开发工具 | MCP 服务器构建、代码生成、调试辅助 |
| 安全合规 | 合同审核、涉政内容审校、文档对比 |

### 安装技能

1. 在技能广场浏览或搜索目标技能
2. 点击"安装"按钮
3. 等待技能文件下载并注册到本地
4. 安装完成后，技能即可在当前工作空间使用

::: tip 技能安装安全
技能广场的技能在上架前需通过官方安全审查，安装前可查看技能的相关信息。
:::

## 1.5.3 实操：安装并使用合同审核技能

### 步骤 1：安装技能

1. 打开技能广场
2. 搜索"合同审核"或"contract-review"
3. 点击安装，等待安装完成

### 步骤 2：准备合同文件

将一份待审核的合同文件（PDF 或 Word 格式）上传到工作空间。

### 步骤 3：调用技能执行任务

在输入框中输入：

```
@contract-review 请审核这份采购合同的以下风险点：
1. 付款条件是否对我方不利
2. 知识产权归属条款
3. 违约责任限制
4. 保密条款范围
5. 争议解决地约定
```

### 步骤 4：查看审核结果

合同审核技能会输出：

- **结构化风险报告**：按风险等级（高/中/低）分类列出问题条款
- **批注版文档**：在原文档对应位置插入批注，标注问题类型和修改建议
- **综合意见**：整体风险评估和修改优先级建议
- **业务流程图**：用 Mermaid 图表展示合同涉及的业务流程

## 1.5.4 技能的 @ 调用机制

在输入框中使用 @ 符号可以快速唤起指定技能：

```
@技能名称 你的任务描述...
```

- 输入 @ 后会弹出已安装技能列表，支持搜索
- 选择技能后继续输入任务描述
- 同一条指令中可以 @ 多个技能协同工作

## 1.5.5 技能管理

### 启用与禁用

已安装的技能可以随时启用或禁用：
- **禁用**：技能不再出现在 @ 调用列表中，但不卸载
- **启用**：恢复技能的可用状态

### 卸载技能

不再需要的技能可以卸载，释放本地存储空间。卸载会同时清理技能文件和元数据注册信息。

### 技能更新

技能作者发布新版本后，技能广场会提示更新。部分技能支持后台自动更新。

::: warning 内置技能说明
Excel、Word、PPT、PDF 等核心办公技能为内置技能，具体可操作行为以实际产品为准。
:::

## 1.5.6 技能开发与发布

对于有开发能力的用户或企业，可以自主开发技能并发布：

### 技能结构

一个完整的技能包含：

```
my-skill/
├── SKILL.md              # 技能指令文件（核心）
├── scripts/              # 脚本文件
├── references/           # 参考文档
└── templates/            # 模板文件
```

### SKILL.md 的作用

SKILL.md 是技能的核心指令文件，定义了技能的名称、描述、触发条件和执行逻辑。TeleAgent 读取 SKILL.md 来理解技能的用途和使用方式。

### 发布流程

1. 按照技能规范编写 SKILL.md 和相关脚本
2. 将技能打包为 ZIP 格式
3. 通过技能广场或企业管理后台提交发布
4. 经过安全审查后上架

::: tip 技能的可移植性
好的技能应该保证他人部署也能直接使用——不依赖本地密钥、不硬编码文件路径、无缓存可运行。这是技能上架的基本要求。
:::

## 本章小结

技能是 TeleAgent 从"通用助手"进化为"专业工具"的关键。通过技能广场，你可以按需扩展 TeleAgent 的能力边界。下一章我们将介绍 MCP 连接器——另一种扩展方式，让 TeleAgent 能够连接外部系统和数据源。
