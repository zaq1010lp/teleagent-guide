# 1.3 界面、设置与工作空间

## 本章目标

熟悉 TeleAgent 工作台的界面布局，掌握工作空间的创建与切换，完成基础系统配置——为后续高效使用打下基础。

## 1.3.1 工作台总览

TeleAgent 的工作台采用「左侧导航栏 + 中央主对话区域」的两段式布局设计，核心区域包括：

```
┌──────┬───────────────────────────────────────────┐
│      │  预设任务卡片区                            │
│ 左侧  ├───────────────────────────────────────────┤
│ 导航  │                                            │
│ 栏    │  中央主对话区域                             │
│      │  （任务描述、执行过程、交付结果）            │
│      │                                            │
│      ├───────────────────────────────────────────┤
│      │  底部输入框（输入指令 | 工作空间 | 模型选择）  │
└──────┴───────────────────────────────────────────┘
```

### 核心区域说明

| 区域 | 功能 |
| --- | --- |
| 左侧导航栏 | 新建任务、技能管理、即时通讯、任务列表四大入口 |
| 预设任务卡片区 | 横排卡片展示常见场景的标准化提示词模板，点击即填入输入框 |
| 中央主对话区域 | 显示任务描述、思考过程、执行步骤和最终交付结果 |
| 底部输入框 | 输入自然语言指令，左下角显示工作空间路径，右下角提供模型选择器 |

## 1.3.2 四大核心能力入口

工作台首页清晰展示四大核心办公能力：

1. **整理文件**：文件分类、归档、批量重命名、格式转换
2. **深度调研与资讯**：联网搜索、多源分析、结构化报告生成
3. **写文档做 PPT**：Word 文档撰写、Excel 表格处理、PPT 演示文稿制作
4. **写代码做应用**：代码编写、脚本生成、应用开发辅助

用户只需在底部输入框描述需求，TeleAgent 就会自动理解意图并开始执行。

## 1.3.3 工作空间管理

工作空间是 TeleAgent 的独立运行环境，每个工作空间维护独立的文件、技能和任务上下文。

### 为什么需要工作空间

- **项目隔离**：不同项目的文件和对话互不干扰
- **上下文保持**：在多个工作空间间快速切换，保持各自的工作上下文
- **技能定制**：不同工作空间可启用不同的技能组合

### 创建与切换

1. **新建工作空间**：点击底部输入框左下角的工作空间指示器，选择"新建"，输入名称和描述
2. **切换工作空间**：点击工作空间指示器，从下拉列表中选择目标空间
3. **删除工作空间**：在工作空间设置中选择删除，该空间的文件和历史对话将被清除

::: tip 工作空间命名建议
按照项目名称或业务场景命名，如"Q3经营分析"、"合同审核中心"、"客户跟进"，避免使用"测试1"、"新建空间"等无意义名称。
:::

## 1.3.4 文件处理

工作空间内的文件管理是 TeleAgent 的基础能力：

### 文件上传

- **拖拽上传**：将文件直接拖入对话区域
- **选择上传**：点击输入框旁的附件按钮选择文件
- **支持格式**：PDF、Word（.docx）、Excel（.xlsx）、PPT（.pptx）、图片（png/jpg）、CSV、TXT、Markdown 等

### 文件列表

上传后的文件会出现在工作空间的文件列表中，支持查看、删除和重新引用。每个工作空间的文件相互独立。

## 1.3.5 系统设置

进入"设置"页面，可以进行以下配置：

### 模型配置

- 选择工作空间默认使用的大语言模型
- 不同模型在速度、能力和 Token 消耗上各有侧重
- 可根据任务类型灵活切换

### MCP 工具配置

- 管理已连接的 MCP 工具
- 配置工具的连接参数和权限范围
- 查看 MCP 工具的运行状态

### 界面偏好

- **语言**：简体中文（默认）/ English
- **主题**：浅色模式 / 深色模式 / 跟随系统
- **通知**：任务完成通知、系统消息提醒

### 运行参数

- **超时时间**：单步任务的最大执行时间
- **重试策略**：任务失败时的自动重试次数和间隔
- **通知设置**：任务完成通知、需人工介入通知等开关

## 1.3.6 数据统计

工作空间提供 Token 使用统计功能：

- **当前周期用量**：展示当前工作空间的 Token 消耗情况
- **历史趋势**：查看 Token 使用量的变化曲线
- **模型维度筛选**：按模型查看 Token 消耗分布，帮助优化使用策略

::: tip Token 是什么？
Token 是大语言模型处理文本的最小单位。一个中文字符约等于 1-2 个 Token，一个英文单词约等于 1-3 个 Token。模型的输入和输出都消耗 Token，Token 用量直接影响使用成本。
:::

## 1.3.7 技能管理

在工作台中可以管理当前工作空间已安装的技能：

- **技能广场入口**：浏览和添加平台预置技能
- **@调用技能**：在输入框中输入 @ 符号唤起指定技能
- **技能配置**：对已添加技能进行参数调整
- **启用/禁用**：根据需要灵活控制技能的可用状态
